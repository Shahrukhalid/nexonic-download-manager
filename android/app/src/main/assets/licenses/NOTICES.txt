SOURCE CODE (Corresponding Source)
- Nexonic Download Manager, exactly as built for each release: the matching version
  tag at https://github.com/Shahrukhalid/nexonic-download-manager (build steps:
  android/README.md). The source archive is also attached to every GitHub release.
- Every release also has Android-GPL-Sources.tar.gz attached: the source of
  youtubedl-android 0.18.1 (https://github.com/yausername/youtubedl-android),
  the Termux recipes and patches used to build its Python
  (https://github.com/termux/termux-packages), and the original source archive
  of every library it is built with.
- FFmpeg is built unmodified from the FFmpeg n7.1 source by scripts/build-ffmpeg.sh
  in the Nexonic repository above (https://github.com/FFmpeg/FFmpeg/tree/n7.1).
If you cannot get any of this source, ask at
https://github.com/Shahrukhalid/nexonic-download-manager/issues and it will be
provided free of charge for at least three years after the last release that
included it.
